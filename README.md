# Mayur Fashion™ — Luxury Ethnic Wear & Global Wholesale Platform
*Manohar Dresses • Estd. 1991 • Ahmedabad, Gujarat, India*

A high-performance, luxury web platform and digital catalog lookbook for **Mayur Fashion**, showcasing premium handcrafted Kurti sets, Chanderi silks, Artisanal Zardozi embroidery, Afghani sets, and Anarkalis with full size grading from **M to 5XL**.

---

## ✨ Features & Highlights

- **Luxury Aesthetics & Color Harmony**: Tailored crimson `#EF233C`, sage `#C8D6BF`, warm sand `#ECE5CE`, soft rose `#F2BCB6`, and light cream `#EDEBE6`.
- **Bidirectional Hero Entrance**: Dynamic cinematic entrance motion where left and right elements morph smoothly onto the screen with luxury cubic-bezier easing.
- **Complete 2026 Collection Catalog**: High-resolution studio product photos with multi-angle galleries, fabric breakdowns, stitching details, and size guides.
- **Interactive Wholesale Inquiry Drawer**: Instant inquiry shortlist builder with direct one-click WhatsApp export to Mayur Peswani (`+91 99788 31115`).
- **Digital Lookbook Viewer**: Embedded high-definition catalog viewer for domestic and international B2B buyers.
- **Studio Photo AI Optimization**: Precision bounding-box and background cleaning pipeline ensuring head-to-toe garment and model visibility.
- **Ultra-Fast Performance**: Built on React 18 and Vite for near-instant page load and responsive mobile-first performance.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Icons**: Lucide React
- **Typography**: Playfair Display, Cinzel, Plus Jakarta Sans
- **Styling**: Vanilla CSS Design Tokens, Glassmorphism, Micro-animations
- **Data Pipeline**: Python 3, YOLOv8, Pillow / OpenCV

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/KAVYAANPRO/Mayur-Fashion.git
cd Mayur-Fashion
```

2. Install dependencies:
```bash
npm install
```

3. Start local development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
